🇧🇾 Диспансеризация в Беларуси — Справочно-практический сервис
Диспансеризация в Беларуси — это современный информационный веб-сервис для пациентов, родителей и медицинских работников. Он помогает быстро и понятно разобраться в порядке проведения профилактических осмотров, рассчитать персональный маршрут обследований и узнать актуальные нормативы.

Сервис опирается на официальные документы Министерства здравоохранения Республики Беларусь (Постановления № 173 и № 174) и предлагает пользователю интерактивный расчет всего за 1–2 минуты.

⚠️ Дисклеймер: Данное приложение носит исключительно справочный и информационный характер. Оно не ставит диагнозы, не назначает лечение и не заменяет полноценную консультацию врача. Вся логика расчетов выполняется локально в браузере — ваши персональные данные (дата рождения, пол) не отправляются на сервер и не сохраняются.

🛠 Технологический стек
Проект разработан с использованием актуального стека веб-разработки:

Фреймворк: Next.js (Static Export)

Язык: TypeScript

Стилизация: Tailwind CSS

Данные: JSON-файлы (/data/*.json)

Тестирование: Unit-тесты для чистой логики расчета (Jest / Vitest)

Деплой: Vercel

🚀 Быстрый запуск и разработка

Требования

Node.js (версии 18.18 или выше)

npm или pnpm

Установка и запуск

bash
# 1. Установка зависимостей
npm install

# 2. Запуск локального сервера разработки
npm run dev
Сайт будет доступен по адресу: http://localhost:3000
