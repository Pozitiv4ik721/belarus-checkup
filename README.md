# 🩺 Диспансеризация в Беларуси — Интерактивный справочник здоровья

**Диспансеризация в Беларуси** — это информационный веб-сервис для быстрой и понятной оценки того, какие медицинские обследования положены взрослым и детям. Проект создан на основе официальных постановлений Министерства здравоохранения Республики Беларусь и предлагает пользователю получить персональный маршрут здоровья за 1–2 минуты.

> ⚠️ **Дисклеймер:** Данное приложение носит исключительно информационный характер и не заменяет полноценную консультацию врача или лабораторную диагностику. Все расчеты производятся локально в браузере — ваши данные (дата рождения, пол) **не отправляются на сервер и не сохраняются**.

---

## 🌟 Ключевые возможности

*   **Линия возрастов:** Интерактивный ползунок для быстрого просмотра обследований по возрасту.
*   **Персональный маршрут:** Расчет исследований для взрослых (18–39 лет и 40+) с учетом пенсионного периода.
*   **Детская диспансеризация:** Схемы по приложениям 1 и 2 (дети до года и от 1 до 17 лет), включая факторы риска.
*   **Инструменты для медработников:** Чек-лист проведения, группы здоровья, калькулятор охвата и печатная форма 3/у-ДР.
*   **Доступность (a11y):** Версия для слабовидящих, темная тема, поддержка скринридеров и навигация с клавиатуры.
*   **Локализация:** Полная поддержка русского и белорусского языков.
*   **Автономность:** Работает как Static Export (один HTML-файл), не требует бэкенда и баз данных.

---

## 🛠️ Технологический стек

Проект написан на «чистом» стеке без использования тяжелых фреймворков, что обеспечивает мгновенную загрузку и высокую приватность:

*   **Язык:** Vanilla JavaScript (ES6+), HTML5, CSS3.
*   **Стилизация:** Нативный CSS с переменными (CSS Custom Properties) для темной/светлой темы и версии для слабовидящих.
*   **Иконки:** Инлайн SVG (стиль Lucide).
*   **Шрифты:** Google Fonts (Golos Text, Source Serif 4).
*   **Тестирование:** Встроенный самотест (доступен по хэшу `#test`).

---

## 🚀 Быстрый запуск и разработка

Проект не требует сборки (npm, webpack и т.д.). Весь код находится в одном файле `index.html`.

### Требования
*   Любой современный браузер (Chrome, Firefox, Safari, Edge).
*   (Опционально) Локальный веб-сервер для корректной работы некоторых функций (например, `Live Server` в VS Code или `python -m http.server`).
