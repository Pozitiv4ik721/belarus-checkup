# 🩺 Диспансеризация в Беларуси — Интерактивный справочник здоровья

**Диспансеризация в Беларуси** — это информационный веб-сервис для быстрой и понятной оценки того, какие медицинские обследования положены взрослым и детям. Проект создан на основе официальных постановлений Министерства здравоохранения Республики Беларусь (№ 173 и № 174) и предлагает пользователю получить персональный маршрут здоровья за 1–2 минуты.

> ⚠️ Дисклеймер: Данное приложение носит исключительно информационный характер и не заменяет полноценную консультацию врача или лабораторную диагностику. Все расчеты производятся локально в браузере — ваши данные не отправляются на сервер.

## 🛠️ Технологический стек

Проект разработан с использованием актуального стека веб-разработки:

- **Фреймворк:** [Next.js](https://nextjs.org/) (Static Export)
- **Язык:** [TypeScript](https://www.typescriptlang.org/)
- **Стилизация:** [Tailwind CSS](https://tailwindcss.com/)
- **Иконки и Анимации:** Lucide React, Framer Motion
- **Тестирование:** Чистые функции с Unit-тестами
